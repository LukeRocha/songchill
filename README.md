# Songchill

A static **music player UI built with pure HTML and CSS**.
All page interactions like menus, dropdowns, blur effects, and icon animations are implemented **without JavaScript**. The layout is **responsive** and the CSS architecture follows **BEM (Block Element Modifier)**.

**Live demo:** https://songchill.netlify.app/

---

## Overview

- **Pure HTML + CSS:** no JavaScript on the page.
- **BEM methodology:** clear, modular, and scalable CSS.
- **Responsive design:** adapts from mobile to desktop.
- **Quality focus:** structure, accessibility, and performance validated with Lighthouse.

---

## Tech

- **HTML5** (semantic structure)
- **CSS3** (BEM, transitions, keyframes)
- **Prettier** (code formatting)
- **Live Server** (local preview during development)

---

## Getting Started

You can open the project’s `index.html` directly in your browser.

Or use the scripts below for a local server and formatting.

---

## Installation

```bash
npm install
```

## Run locally
```bash
npm run live
```

## Formatting (Prettier)
```bash
npm run fmt
```
